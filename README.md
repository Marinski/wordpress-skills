# WordPress Skills

A curated marketplace of **Claude Code agent skills** for WordPress
development and operations. Each plugin bundles structured expertise that
makes Claude Code proficient in WordPress domains — from core platform
concepts and hooks to plugin/theme development, security, performance,
REST API integration, and content synchronization.

## Quick start

```bash
# Install all plugins
claude plugin install . --all

# Or install individual plugins
claude plugin install ./plugins/wordpress-platform
claude plugin install ./plugins/wordpress-development
claude plugin install ./plugins/wordpress-content-sync
```

## Available plugins

| Plugin | Description |
|--------|-------------|
| [wordpress-platform](./plugins/wordpress-platform) | Core concepts, hooks, database, performance, security |
| [wordpress-development](./plugins/wordpress-development) | Plugin dev, theme dev, REST API |
| [wordpress-content-sync](./plugins/wordpress-content-sync) | Bidirectional content sync via the WP REST API |
