# wordpress-development

Agent skills for building on top of WordPress — plugins, themes, and
API-facing integration.

## Included skills

- **Plugin Development** — foundations, lifecycle hooks, admin menus and settings pages, shortcodes, privacy hooks, internationalization, JavaScript/AJAX/cron, must-use plugins, WordPress.org release workflow
- **Theme Development** — classic and block themes, template hierarchy, `theme.json` and global styles, patterns, Customizer, accessibility, theme review
- **REST API** — custom endpoints, controllers and schema, HTTP API clients, authentication, XML-RPC legacy integration

## Usage

```bash
claude plugin install ./plugins/wordpress-development
```

Then reference skills by name in your prompts (e.g. "use wordpress-theme-dev").
