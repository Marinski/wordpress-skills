# WordPress Theme Development

Use this skill for presentation-layer work in WordPress themes, including classic and block-theme workflows.

## When To Use

- Theme setup, file structure, templates, template hierarchy, or template parts
- `theme.json`, global styles, presets, or block-theme decisions
- Patterns, classic theme features, Customizer behavior, CSS-facing theme concerns, or accessibility/review work
- Theme-side presentation features such as feeds, post formats, or oEmbed-facing behavior

## Workflow

1. Determine whether the task is about presentation, editor/theme configuration, or theme release quality.
2. Read the matching reference from `./references/`.
3. Pull in core references only when the issue crosses into platform/runtime behavior.
4. Keep content portability and business logic outside the theme when possible.
